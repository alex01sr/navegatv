# NavegaTV

Módulo de [TizenBrew](https://github.com/reisxd/TizenBrew) para televisores Samsung (Tizen).

- Bloquea ventanas emergentes, enlaces invisibles sobre la página y redirecciones a otros sitios.
- Cursor con las flechas del control remoto (OK = clic, CH ▲▼ = desplazar).
- Modo TV: el video que se reproduce pasa a pantalla completa con controles del control remoto
  (◀ ▶ atrasar/adelantar, OK pausa, CH ▲▼ ±1 min, Atrás salir).
- Botón Atrás: menú con búsqueda, página anterior, favoritos, zoom y salir.

## Instalar
En TizenBrew → Module Manager → agregar módulo de GitHub: `alex01sr/navegatv`
